## 📂 Featured Projects

### 1. 🧾 K2 Summit | AI-Powered Tax Document Extraction

- Worked on AI-powered tax document processing and extraction workflows for tax forms and supporting accounting records.
- Developed and enhanced custom extraction models for tax schedules and forms using Azure AI Document Intelligence.
- Worked on General Ledger extraction, OCR processing, field mapping, and validation of extracted financial data.

**Technologies:** Python, Azure AI Document Intelligence, Custom OCR Models, LLMs, Document Processing, Data Extraction

---

### 2. 🌍 MSC (Morning Star Center) | Microsoft Fabric & Power BI

- Contributed to the end-to-end implementation across data engineering, business analysis, Power BI dashboard development, testing, and client collaboration to deliver scalable analytics solutions.
- Designed and developed Microsoft Fabric pipelines and notebooks to extract, transform, and integrate data from BetterUnite, Stripe, NetSuite, and SharePoint Excel, storing curated data in the Fabric Warehouse.
- Gathered business requirements, defined KPIs, and developed **7 interactive Power BI dashboards** by connecting to the Fabric Warehouse through SQL Endpoints, delivering executive, campaign, financial, and operational insights.

**Technologies:** Microsoft Fabric, Power BI, Fabric Pipelines, Notebooks, SQL Endpoints, Fabric Warehouse, BetterUnite, Stripe, NetSuite, Semantic Models

---

### 3. 🏎️ Barrett-Jackson | Azure Data Integration Pipelines

- Designed and developed end-to-end Azure Data Factory pipelines to ingest data from multiple enterprise sources into Azure for centralized analytics and reporting.
- Built data ingestion pipelines to extract social media analytics from Sprout Social (Facebook, Instagram, LinkedIn, X, YouTube, TikTok) and near real-time mobile application data from Google BigQuery.
- Implemented automated scheduling, incremental data loading, monitoring, and error handling to ensure reliable, scalable, and efficient data integration workflows.

**Technologies:** Azure Data Factory, Azure Data Lake Storage, Google BigQuery, Sprout Social API

---

### 4. 🏭 AI-Based Predictive Maintenance & Machine Failure Detection | Smart Manufacturing

- Designed and developed an end-to-end predictive maintenance solution using IoT sensor telemetry and historical maintenance data, performing data preprocessing, EDA, feature engineering, and feature selection to improve model accuracy.
- Built, trained, and optimized Machine Learning and Deep Learning models using TensorFlow to predict machine failures, enabling proactive maintenance and reducing unplanned equipment downtime.
- Developed an automated prediction pipeline and a Power BI dashboard to monitor machine health, failure predictions, maintenance trends, and key operational KPIs.

**Technologies:** Python, Databricks, TensorFlow, Machine Learning, Deep Learning, MLflow, EDA, Power BI

---

### 5. 🔄 SSIS to Microsoft Fabric Migrator

- Designed and developed an accelerator to automate the migration of SSIS packages and projects into Microsoft Fabric Pipelines, Notebooks, and other Fabric artifacts, reducing manual migration effort.
- Built a conversion engine to parse SSIS XML (`.dtsx`, `.dtproj`, `.ispac`) files, transform them into Python object models, and generate Fabric-compatible JSON and code for deployment.
- Developed a Django-based web application with an interactive UI to upload SSIS projects, visualize converted components, and deploy generated Fabric artifacts using APIs.

**Technologies:** Python, Django, Microsoft Fabric, XML Parsing, REST APIs, JSON, SSIS

---

### 6. ☁️ Azure (ADF & Synapse) to Microsoft Fabric Migrator

- Worked on migration solutions focused on transitioning Azure Data Factory and Azure Synapse workloads to Microsoft Fabric.
- Focused on modernizing existing data integration and analytics workflows using Microsoft Fabric technologies.

**Technologies:** Microsoft Fabric, Azure Data Factory, Azure Synapse Analytics, Python
